# XT250 Dash

Phone dashboard for a Yamaha XT250. Open it on an iPhone, add it to the Home Screen, tap **TURN ON GPS**.

Live at: https://jeffgibbs360.github.io/XT250-Dash/

**Stage 1 (now):** GPS speed, trip, max, average moving speed, ride time, heading, altitude, clock, day/night mode, map with ride track, turn-by-turn navigation (road route or straight line).
**Stage 2 (planned):** ESP32 Bluetooth sensor box for gear indicator, battery voltage and oil temp.
